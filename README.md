# libskybrush-rs

Parsing and playback of Skybrush drone show files in Rust.

This is a rewrite of the C library
[libskybrush](https://github.com/skybrush-io/libskybrush), with feature parity
to version 6.0.2 of the C library where possible. The API is idiomatic Rust and
does not follow the conventions of the C library.

The crate is `no_std` and requires a global allocator only, so it can be used
in firmware, e.g., in loadable ArduPilot modules. Playback does not allocate,
and malformed show files are reported as errors, never as panics.

## Usage

```toml
[dependencies]
skybrush = "0.1"
```

```rust
use skybrush::control::ShowController;
use skybrush::formats::binary::BinaryFile;
use skybrush::screenplay::Screenplay;

let file = BinaryFile::new(&bytes)?;
let screenplay = Screenplay::from_binary_file(&file)?;
let mut controller = ShowController::new(screenplay);

// What the drone should do 2.5 s into the show
controller.update_time_msec(2500);
let position = controller.current_output().position();
```

See the [documentation](https://docs.rs/skybrush) for the components of a
show and their players.

The minimum supported Rust version is 1.98.1.

## Testing

The behaviour of the crate is checked against test data generated by the C
library, vendored in `tests/oracle` (see `scripts/vendor-oracle.sh`).
`cargo test` runs these tests; `fuzz/` has the fuzz targets.
